# AI Mail Sorter 📧🤖

## Over het project
Ons project is de AI Mail Sorter. Dit is een slimme applicatie die met behulp van kunstmatige intelligentie inkomende e-mails automatisch analyseert en categoriseert. Het systeem herkent het onderwerp en plaatst de mail direct in de juiste map (zoals Werk, school, Privé, Facturen, of Spam). Hierdoor houd je altijd een overzichtelijke inbox en bespaar je veel tijd.
